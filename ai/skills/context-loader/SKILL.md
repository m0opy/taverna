# Skill: Context Loader

## Назначение

Загрузить минимальный, но достаточный контекст Taverna перед любым изменением. Skill предотвращает работу по устаревшим task-файлам и смешивание архитектурных решений.

## Обязательный порядок

1. Прочитать `ai/project-context.md`.
2. Определить scope по `ai/docs/requirements.md`.
3. Прочитать только релевантные разделы `architecture.md`, `data-model.md`, `api.md` и `testing.md`.
4. Найти существующий код и тесты по затрагиваемому модулю.
5. Проверить `git status` и не перезаписывать пользовательские изменения.

## Перед стартом сообщить

- какую пользовательскую проблему решает изменение;
- какие файлы и слои будут затронуты;
- какой контракт и какое поведение считаются готовыми;
- какие проверки будут запущены.

## Запрещено

- считать task или prompt источником истины, если он противоречит коду и canonical docs;
- менять код до определения границ и проверок;
- добавлять новые зависимости или альтернативный стек без явного решения;
- заявлять production-ready на основании локального `build`.

## Результат

В конце работы обновить только те docs/status, которые действительно изменились, и указать фактические проверки и оставшиеся gaps.
